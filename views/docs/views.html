Views & Templates

Powerful template engine with layouts, components, and slots

Rendering Views

Views live in views/ as .html files. Render them from controllers:

Response.view("pages/home", { title: "Welcome", user: currentUser });

The path pages/home resolves to views/pages/home.html.

Variables

Output variables with double curly braces (HTML-escaped by default):

@verbatim 
{{ title }}
{{ user.name }}
{{ user.address.city }}

For raw/unescaped output:

{!! rawHtml !!}
@endverbatim

Control Flow

If / Else

@verbatim 
@if(isAdmin)
    
Welcome, admin!

@elseif(isMod)
    
Welcome, moderator!

@else
    
Welcome, user!

@endif
@endverbatim

Unless

@verbatim 
@unless(banned)
    
You have access.

@endunless
@endverbatim

Foreach

@verbatim 
@foreach(users as user)
    
{{ loop.iteration }}. {{ user.name }}

@endforeach
@endverbatim

Loop variables available inside @foreach:

VariableDescription
loop.indexZero-based index
loop.iterationOne-based iteration count
loop.firstTrue on first iteration
loop.lastTrue on last iteration
loop.countTotal items in array

Key/Value Foreach

@verbatim 
@foreach(items as index, item)
    
{{ index }}: {{ item }}

@endforeach
@endverbatim

For Loop

@verbatim 
@for(i = 1; i <= 10; i++)
    
Item {{ i }}

@endfor
@endverbatim

Includes

Include another template (inherits parent scope):

@verbatim 
@include('partials/header')
@include('partials/card', { title: 'Hello', description: 'World' })
@endverbatim

Layouts

Create a layout in views/layouts/:

@verbatim 
<!-- views/layouts/app.html -->
<!DOCTYPE html>
<html>
<head>
    <title>@yield('title', 'Default Title')</title>
</head>
<body>
    <header>...</header>
    @yield('content')
    <footer>...</footer>
</body>
</html>

Extend it from a page:

@extends('layouts/app')

@section('title')
My Page Title
@endsection

@section('content')
<h1>Hello World</h1>
<p>Page content here.</p>
@endsection
@endverbatim

Layouts can extend other layouts — unlimited depth.

Components

Create reusable components with props and slots:

@verbatim 
<!-- views/components/alert.html -->
<div class="alert alert-{{ $props.type }}">
    @if($slots.title)
    <strong>{!! $slots.title !!}</strong>
    @endif
    {!! $slot !!}
</div>
@endverbatim

Use them in templates:

@verbatim 
@component('components/alert', { type: 'success' })
    <p>Operation completed!</p>
@endcomponent

@component('components/alert', { type: 'error' })
    @slot('title')
    Error!
    @endslot
    <p>Something went wrong.</p>
@endcomponent
@endverbatim

Stacks

Push content from anywhere (even components) and render at a specific point:

@verbatim 
<!-- In your layout -->
@stack('scripts')

<!-- In any template/component -->
@push('scripts')
<script src="/js/chart.js"></script>
@endpush
@endverbatim

Once

Render a block only once, even if it's inside a loop:

@verbatim 
@foreach(items as item)
    @once
    <link rel="stylesheet" href="/css/items.css">
    @endonce
    <div>{{ item.name }}</div>
@endforeach
@endverbatim

Utility Directives

@verbatim 
<!-- Output JSON (raw, for use in script tags) -->
<script>const config = @json(config);</script>

<!-- Conditional CSS classes -->
<div class="@class({ active: isActive, hidden: isHidden })">...</div>

<!-- Form attribute helpers -->
<input type="checkbox" @checked(rememberMe)>
<option @selected(role === 'admin')>Admin</option>
<button @disabled(formLocked)>Submit</button>
<input @required(isRequired)>
@endverbatim @endsection
