Authentication

Session-based auth out of the box

How It Works

JS-CGI-MVC uses cookie-based sessions. When a user logs in, their ID is stored in the session. On each request, Auth.init() loads the user from the database.

Registration

import { Auth } from "../../framework/Auth.js";
import { DB } from "../../framework/DB.js";

const id = DB.table("users").insert({
    name: "Alice",
    email: "alice@example.com",
    password: Auth.hashPassword("secret123"),
    created_at: new Date().toISOString()
});

// Log them in immediately
Auth.attempt("alice@example.com", "secret123");

Login

if (Auth.attempt(email, password)) {
    // Success — session is set
    const user = Auth.user();
} else {
    // Invalid credentials
}

Checking Auth State

// In a controller
if (Auth.check()) {
    const user = Auth.user();
    // user.id, user.name, user.email
}

// In middleware (the built-in "auth" middleware does this)
if (!Auth.check()) {
    Response.json({ error: "Unauthorized" }, 401);
    return false;
}

Logout

Auth.logout();

Protecting Routes

Use the built-in auth middleware:

Router.get("/dashboard", DashboardController.index, ["auth"]);

Router.group({ prefix: "/account", middleware: ["auth"] }, () => {
    Router.get("/settings", AccountController.settings);
    Router.post("/settings", AccountController.update);
});
