Routing

Map URLs to controller actions

Basic Routes

Routes are defined in routes.js using the Router:

import { Router } from "./framework/Router.js";
import { PageController } from "./app/controllers/PageController.js";

Router.get("/", PageController.index);
Router.post("/contact", PageController.submit);
Router.put("/posts/:id", PageController.update);
Router.delete("/posts/:id", PageController.destroy);

Route Parameters

Use :param syntax to capture URL segments:

Router.get("/users/:id", UserController.show);
Router.get("/posts/:postId/comments/:commentId", CommentController.show);

Parameters are available in the controller via ctx.params:

show(ctx) {
    const userId = ctx.params.id;
}

Route Groups

Group routes that share a prefix or middleware:

Router.group({ prefix: "/admin", middleware: ["auth"] }, () => {
    Router.get("/dashboard", AdminController.dashboard);
    Router.get("/users", AdminController.users);
});

Per-Route Middleware

Apply middleware to individual routes:

Router.get("/profile", ProfileController.show, ["auth"]);
