Controllers

Handle requests and return responses

Creating a Controller

Controllers are objects with handler methods. Create them in app/controllers/:

import { Response } from "../../framework/Response.js";

export const PostController = {
    index(ctx) {
        Response.json({ posts: [] });
    },

    show(ctx) {
        const id = ctx.params.id;
        Response.json({ post: { id } });
    },

    store(ctx) {
        const { title, body } = ctx.body;
        Response.json({ message: "Created" }, 201);
    }
};

The Context Object

Every handler receives a ctx object:

PropertyDescription
ctx.paramsURL parameters (e.g. :id)
ctx.queryQuery string parameters
ctx.bodyParsed request body (JSON)
ctx.headersRequest headers
ctx.cookiesRequest cookies

Rendering Views

Use Response.view() to render a template:

import { Response } from "../../framework/Response.js";
import { DB } from "../../framework/DB.js";

export const PostController = {
    index(ctx) {
        const posts = DB.table("posts").orderBy("created_at", "DESC").get();
        Response.view("pages/posts/index", { posts });
    },

    show(ctx) {
        const post = DB.table("posts").where("id", ctx.params.id).first();
        Response.view("pages/posts/show", { post });
    }
};

Response Methods

// JSON response
Response.json({ key: "value" });
Response.json({ error: "Not found" }, 404);

// HTML response
Response.html("<h1>Hello</h1>");

// Render a view template
Response.view("pages/home", { title: "Welcome" });

// Redirect
Response.redirect("/login");
Response.redirect("/old-page", 301);

// Error page
Response.abort(403, "Forbidden");
