Learn how to build applications with JS-CGI-MVC

What is JS-CGI-MVC?

JS-CGI-MVC is a lightweight MVC framework for JS-CGI. It brings familiar patterns from frameworks like Laravel to server-side JavaScript — without Node.js, npm, or build tools.

Drop your files on a server and they just work.

Features

  • Expressive routing with parameters and groups
  • Controller-based request handling
  • Middleware pipeline for auth, validation, and more
  • SQLite query builder with chainable API
  • Session-based authentication out of the box
  • Powerful template engine with layouts, components, and slots

Project Structure

/var/www/js/
├── index.js                 # Front controller
├── routes.js                # Route definitions
├── framework/
│   ├── Router.js            # Route registration & matching
│   ├── Pipeline.js          # Middleware runner
│   ├── DB.js                # SQLite query builder
│   ├── Auth.js              # Authentication helpers
│   ├── Response.js          # Response utilities
│   └── View.js              # Template engine
├── app/
│   ├── controllers/         # Your controllers
│   └── middleware/          # Your middleware
├── views/
│   ├── layouts/             # Layout templates
│   ├── components/          # Reusable components
│   ├── partials/            # Include partials
│   └── pages/               # Page templates
├── database/
│   └── migrations/          # Schema migrations
└── storage/
    └── app.db               # SQLite database

Quick Start

1. Define a route in routes.js

2. Create a controller in app/controllers/

3. Create a view in views/

4. Visit the URL — that's it.
