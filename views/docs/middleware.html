Middleware

Filter requests before they reach your controllers

Creating Middleware

Middleware are functions that return true to continue or false to halt:

import { Response } from "../../framework/Response.js";

export function adminMiddleware(ctx) {
    if (!ctx.headers["x-admin-key"]) {
        Response.json({ error: "Forbidden" }, 403);
        return false;
    }
    return true;
}

Registering Middleware

Register middleware by name in index.js:

import { Pipeline } from "./framework/Pipeline.js";
import { adminMiddleware } from "./app/middleware/admin.js";

Pipeline.register("admin", adminMiddleware);

Applying Middleware

Use the registered name in routes:

// Single route
Router.get("/admin", AdminController.index, ["admin"]);

// Route group
Router.group({ prefix: "/admin", middleware: ["auth", "admin"] }, () => {
    Router.get("/dashboard", AdminController.dashboard);
});

Middleware Order

Middleware runs in the order specified. If any returns false, subsequent middleware and the controller are skipped.
